# Project direction

N.E.M.O. is a Windows desktop assistant for conversation grounded in an Obsidian vault, with local storage and a locally running Ollama model by default.

## Prepared in 1.1.0

- Natural-language passage ranking, model-assisted follow-up resolution and optional local embedding search.
- Broader linked-note retrieval, source excerpts and numbered citations.
- Named conversations, full-history search, summaries, pinned context, export and deletion.
- Streamed replies and cancellation that keeps interrupted answers out of later factual recall.
- Automatic incremental indexing, separate vault indexes, duplicate-filename preservation and atomic saves.
- In-app AI/indexing settings and repeatable tests that do not depend on the user's vault.

## Possible future work

- Evaluate retrieval quality against a growing set of real-world lore questions and model sizes.
- Add optional timeline and contradiction exploration built on cited passages.
- Improve release automation and update installation.

These are areas to explore, not promises or a schedule. Report bugs and suggest features through GitHub Issues.
