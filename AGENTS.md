# N.E.M.O. project instructions

## Publishing app changes

When completing a requested change to the N.E.M.O. application, commit the files changed for that task and push the commit to the current branch on `origin`. The user has authorized this as an ongoing preference.

- Stage only files changed for the requested task; preserve unrelated working-tree changes.
- Do not amend or rewrite existing commits.
- If committing or pushing fails, keep the work intact and report what remains unpublished.
- Publishing means pushing the commit to GitHub. Do not create a release or installer unless requested.
