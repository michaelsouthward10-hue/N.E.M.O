# Mythos website

This is the first static homepage for Mythos, designed as a companion to the N.E.M.O. desktop app.

## Preview

Open `index.html` in a browser. No build step or packages are required.

## Current scope

- Responsive homepage with links for discovery, mythology traditions, quizzes, and art cards.
- A local sample quiz that checks an answer in the browser.
- Links to the N.E.M.O. desktop release.
- A newsletter placeholder. It does not collect or send email addresses until a signup service and privacy wording are chosen.

This folder is a separate website from the N.E.M.O. desktop application. The page does not access a visitor’s Obsidian vault or local AI model.
